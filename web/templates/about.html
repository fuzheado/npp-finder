About npp-finder

npp-finder is a New Pages Patrol triage tool for English Wikipedia. It scans newly created articles and applies filters to surface pages that may need reviewer attention.

How it works

  1. Fetch — queries the MediaWiki API for the most recent mainspace page creations
  2. Analyze — fetches each page's raw wikitext and parses every <ref> tag to detect whether references contain clickable URLs
  3. Enrich — for pages matching your filters, fetches additional metadata: page size, categories, creator edit count, deletion history, and ML quality predictions
  4. Report — displays the results in a sortable table with links to each article and user page

What the columns mean

ColumnWhat it tells you
EditsHow many total edits the creator has — a rough experience gauge. New users with few edits deserve closer scrutiny.
SizePage size in bytes. A 400-byte "article" is almost certainly a stub or junk.
InfDoes the page have an Infobox template? Missing on a person/place/film = red flag.
CatNumber of categories. 0–1 = incomplete, 5+ = well structured.
Del?Has a page with this exact title been deleted before? If Yes, CSD G4 (recreation of deleted material) may apply.
QualityLift Wing ML prediction from Wikimedia's machine learning service. Predicted class: Stub, Start, C, B, GA, or FA. A "Stub" or "Start" prediction means the article is likely incomplete.
Refs / URLTotal references vs how many have a clickable URL. If Refs > 0 and URL = 0, every citation lacks a verifiable link — a key NPP red flag.

Data sources

  • Page data: English Wikipedia via the MediaWiki Action API (list=recentchanges, prop=revisions, prop=info)
  • ML quality: Wikimedia Lift Wing inference service (enwiki-articlequality model). Predicts Stub through FA classes.
  • Deletion history: Checks the deletion log for previously deleted titles (CSD G4 detection).

Privacy

No data is stored server-side beyond the cached JSON results file. Queries are read-only — no Wikipedia login or patrol rights needed (except for unreviewed-only filtering). No user tracking or analytics.
